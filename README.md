# opt

`opt` 是一个简洁、本地优先的微选择记录工具。它只记录已经发生的行为，把判断权完整留给用户：选择可以暂不判断，也可以标为绿色或红色；当天可编辑，过往永久只读。

当前版本是可在 Windows 浏览器中运行的 Web MVP，不是 Windows 安装程序，不包含账号或云同步。

## 本地运行

需要 Node.js 和 pnpm（也可使用 npm）。

```bash
pnpm install
pnpm dev
```

使用 npm 时：

```bash
npm install
npm run dev
```

开发服务器启动后，按终端显示的本地地址在浏览器中打开应用。

## 构建与验证

```bash
pnpm build
pnpm test:run
pnpm test:e2e
```

对应的 npm 命令是：

```bash
npm run build
npm run test:run
npm run test:e2e
```

`test:e2e` 会启动本地 Vite 服务，并使用电脑上已有的 Google Chrome，分别以 1280×800 桌面视口和 390×844 移动视口运行 Playwright 验收。运行前请确认 Chrome 已安装；测试配置不会自动下载额外浏览器。

## 数据与限制

- 所有选择、判断、每日随记和设置仅保存在当前浏览器、当前站点的 Local Storage 中。
- 清除该站点的浏览器数据、重置浏览器配置或更换浏览器会使本地记录丢失；当前版本没有恢复或云端备份能力。
- 日期跨过午夜后，当天会成为不可修改的过往记录。即使设备时钟随后回拨，已经锁定的日期也不会重新开放编辑。
- 浏览器通知只有在用户主动开启并授予权限后才可能显示。普通网页关闭时，通知通常不能保证送达；请不要把它当作系统级提醒。
- 当前版本没有账号、同步、标签、搜索、评分、连续打卡或智能建议。
